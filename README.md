# 1c-my-first-base

Учебная база для освоения 1С:Предприятие.

## Назначение
Тренировочный репозиторий для изучения:
- структуры метаданных 1С (XML-выгрузка),
- версионирования конфигурации,
- базовых операций Git.

## Как открыть базу
1. Установить учебную версию платформы 8.3.27.
2. Создать новую информационную базу (файловый вариант).
3. Развернуть базу из файла `.dt` (если есть) или собрать конфигурацию из XML-файлов.
4. Открыть в режиме «Конфигуратор».

## Текущее состояние
- Справочник «Товары» с реквизитом «Артикул».
- База пустая (без данных).

## Структура репозитория
- XML-файлы конфигурации (метаданные).
- .gitignore — исключения для бинарных файлов.
